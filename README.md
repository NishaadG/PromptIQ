# PromptIQ — local demo

A clickable mockup. No backend, no auth, no API calls — all data is in `lib/mock-data.ts`.

```
npm install
npm run dev     # http://localhost:3000
```

Demo path (≈3 min): `/` → Get started → any email/password → Dashboard → **Start task** →
"Use a sample prompt" (or type your own) → Submit → Claim reward → Leaderboard → Local Lab.
